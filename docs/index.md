## Модуль Branches

Модуль відповідає за управління інформацією про
філії компанії в Україні, Франції та Індії.

Містить клас `Branch` і функції-представлення Django.

::: branches.views
    options:
      show_root_heading: false
      show_source: true
      show_signature: true
      show_if_no_docstring: false
      members_order: source
